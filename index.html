Usage

Drop one file in, mark a canvas, done — it starts itself once the DOM is ready: 

<canvas data-thinking-orb data-state="searching" data-size="20"></canvas>
<script src="thinking-orbs.js"></script>

Or drive it from JavaScript (a container element works too — a canvas is created inside it):

const orb = ThinkingOrbs.create(document.getElementById('stage'), {
  state: 'composing',
  size: 64,        // tuned presets are 64 and 20; any size is interpolated
  theme: 'auto',   // 'auto' | 'dark' | 'light'
  speed: 1,
  paused: false,
  label: 'Composing…' // optional aria-label override
});
orb.setState('searching').setSize(48).setTheme('dark').setSpeed(1.5);
orb.setPaused(true);
orb.destroy();

Attributes: data-state, data-size, data-theme, data-speed, data-paused ("true"), data-label. Behaviour mirrors the original: shared clock across instances, DPR cap 2, auto-pause offscreen / hidden tab, prefers-reduced-motion → static frame, role="img" + per-state label. Geometry is verified numerically against the original golden spec — run node verify.js.
